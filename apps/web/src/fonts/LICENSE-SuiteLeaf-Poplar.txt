SuiteLeaf Poplar is built from Vollkorn Italic 5.001, Copyright 2018 The Vollkorn Project Authors (https://github.com/FAlthausen/Vollkorn-Typeface); Vollkorn Regular 5.001, Copyright 2018 The Vollkorn Project Authors (https://github.com/FAlthausen/Vollkorn-Typeface).

SuiteLeaf changed it so text lays out exactly as in Constantia: outlines were scaled to that font's
units per em and moved sideways to center them in their advance; advance widths, kerning, glyph classes,
and line metrics were set from that font's layout. Where that font joins letters into a ligature, a
ligature glyph was made from this font's own letters, moved closer together. No outline shape was
otherwise changed.

Arabic and Hebrew text lays out close to, but not exactly as, Constantia: this font
chooses contextual forms and ligatures differently there, so lines can be slightly wider or narrower.

Characters the source font lacks were filled with glyphs from these fonts, scaled and centered
the same way (counts are across its styles). Each keeps its own license, reproduced below; all are
compatible with the license of the whole font.
