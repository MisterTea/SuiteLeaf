# Presenter and audience displays

`showFrame` splits one slideshow step. The audience frame is the slide index and whether the screen is blank. It does not include speaker notes. Words on a shape are included. Words in a table are included, and a blank cell is left off. An image uses its description. The presenter frame keeps the notes, the next slide's title, and the elapsed time. The clock is `1:05` at 65 seconds and `1:01:01` after one hour. A time that is not a number is `0:00`. On the last slide the next title is cleared and the frame is ended. A negative elapsed time is stored as 0. A fade whose duration is not a number lasts 0 ms.

`shownElapsedMs` keeps a frozen time while the timer is paused. A live time of 65 seconds stays 65 seconds until pause, then the frozen 10 seconds stays. A paused time that is not a number is 0. The presenter notes header has Pause timer and Resume timer. Starting the show clears a pause. The slideshow was not opened in the browser. A second display was not opened. A slide can store whole seconds from 1 to 3600. While the show is running, that wait moves to the next slide. A blank screen, a paused timer, and a value that is not those whole seconds do not advance. The Transition panel has Advance after seconds. The slideshow was not opened for this wait. A hidden slide is skipped. A plain-text export also skips a hidden slide, including its title and speaker notes. A visible slide still includes its speaker notes. The HTML download skips a hidden slide as well. Marp markdown keeps a hidden slide with `<!-- _hidden: true -->`, and reading that markdown back keeps the slide hidden. A hidden value that is not true or false says `Hidden must be true or false.` and does not repeat the value. A decorative object is left out of the plain-text and HTML downloads. The audience screen also leaves a decorative object out. The object on the slide is unchanged. Speaker notes sit below the slide, and markup in those notes is escaped. A print of the deck includes those notes under the slide. The notes sit after the slide box, so the slide does not clip them, and the next slide starts after those notes. Markup in the notes stays text. A hidden slide's notes are left out. A quote in a picture address or description stays inside the attribute. A slide color that is not a color is left out of the download. A slide with no color uses the master background. A slide that stores its own color keeps that color. The deck passed in is not changed. From slide 1, next lands on slide 3 when slide 2 is hidden, and previous returns to slide 1. Home skips a hidden first slide. The presenter's next label uses that visible slide. With no heading it says `Slide 3`. A blank title uses the master title, so the next label can be `Garden club`. A title that stores `North` stays `North`.

An HTML download keeps an https clip address. A `javascript:` address, and an address that includes a user or a password, is left out of the file. The description stays, and the stored address stays on the clip.

The slideshow uses that split. The audience region records the slide index and the blank flag. The speaker-notes panel reads the presenter notes and the next title. Both regions are still in the same window. A second display was not opened. The slideshow was not opened in the browser.
