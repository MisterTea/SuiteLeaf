# Combo chart

A combo chart draws every series except the last as columns. The last series is a line. A series marked with axis `2` is the line even when it is not last.

The line uses the right-hand value axis. The columns use the left. Saving a workbook chart whose type is `combo` and opening it again keeps that type. The chart type list includes Combo.

An Excel export writes both `barChart` and `lineChart`. The line is attached to value axis `300` on the right. It is not a stacked column chart.
