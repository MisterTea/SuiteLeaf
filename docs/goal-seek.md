# Goal Seek

`goalSeek` searches between a low and a high guess for an input whose formula result is within `0.000001` of the target. The default stops after 60 bisection steps. Each midpoint is reported as a step number. The report does not include the formula or a cell value. An unreachable target says how many steps were tried and names the gap `0.000001`. A target that is not between the formula's results at the two ends is infeasible. Cancellation returns before the next guess and does not write a cell. The function returns a guess. A start that already reaches the target is kept, and the search does not try another guess. The sheet cell that was passed as `start` is left as it was.

`writeGoalSeek` copies a solved guess into one cell. The search itself still does not write. A cell that already has a formula is left unchanged, and a cancelled or infeasible search does not write. The input grid is not changed.

The spreadsheet toolbar button Goal Seek uses the selected cell as the input. A second input, such as C2, searches both cells inside their own bounds. A third input, such as D2, is searched with them. A third address before the second is refused, and a bad third address is not repeated. The formula cell is named, such as B2. Each guess is written, the sheet recalculates, and the formula cell is read. A solved guess stays in the input cell. A search that cannot reach the target, or a formula that does not return a number, puts the input cell back. A formula already in the input cell is not overwritten. With a second input, a solved search says `The search reached the target.` and leaves both cells at values that add to the target. A search that cannot reach it puts both inputs back. The notice does not include the formula. While a search is running, Stop asks it to finish. The search then says `The search stopped. The input cell was put back.` and that sentence does not name the formula cell.

This search assumes the formula moves in one direction between the ends.

The Goal Seek panel can keep the selected input at or below a number when a second input is named. A limit of 3 on a search for 9 keeps that input at most 3. A limit written as `secret-value` says `The limit is not a number.` and does not repeat that word. A limit with no second input says `Name a second input to use the limit.` A constraint can refuse a guess that already reaches the target. `x + y` still reaches 9 with `x` at most 3. A whole number that reaches 4 but must stay at most 2 is not an answer, and the start stays 4. A constraint that throws is not an answer, and the thrown text is not in the notice. `solve` tries up to three inputs. It pins the others at their low or high bound and bisects the remaining input with the same tolerance. A target of 9 for `x + y`, with `x` from 0 to 4 and `y` from 0 to 6, is solved without changing the caller's starts. Starts of 3 and 6 that already add to 9 are kept, and the formula is evaluated once. A target of 9 for two inputs that each stop at 1 is infeasible, and the returned values stay the starts. Cancellation returns those starts. `writeSolver` copies a solved set into the named cells. A formula in any of those cells writes nothing, and an infeasible search writes nothing. The input grid is not changed. An input marked as a whole number is tried only at whole numbers inside its bounds. `x * 2` reaches 6 at `x` of 3 and does not reach 5. A span from 0 through 1,000 is more than 1,000 guesses and is not searched. The start stays 1 or 0. Writing the solved 3 leaves a cell that held `secret-value` unchanged. Each try is counted. Reaching the target says `The search reached the target.` A whole-number search that never hits says how many times it tried. A span that is too wide says so and does not search. The formula and a cell value are not in that sentence. Pivot slicers and structured tables are separate.
