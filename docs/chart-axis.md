# Secondary value axis

A series whose `axis` is `2` uses the right-hand value axis. Any other axis number, or no axis, stays on the left. The right axis is scaled from that series alone. Dues of `40` and `15` keep a larger top than a rate of `0.2` and `0.4`, so the rate is not drawn flat against 40.

An imported Excel line chart draws the right-hand labels when a series uses that axis. A chart with no secondary series still uses one value axis.
