# Spreadsheet cost scan

`inspectSheetCost` walks each sheet's cells, formulas, conditional rules, and charts and records how long that walk took. The report counts those structures. It does not include cell values. A formula containing `NOW`, `RAND`, `RANDBETWEEN`, `TODAY`, `OFFSET`, or `INDIRECT` is counted as volatile and is named when that weight is the largest. The action text says what to change. It is not a measured speedup.

Passing a stop function ends the walk. The function only reads the workbook, so the last saved file is the same object it was given. The spreadsheet toolbar button Cost shows these counts for the open workbook. When phase times are supplied, it names the longest measured phase. A phase that is not one of the workbook phases is left out. Without those times, the note says the pass does not time recalculation. Cell values are not shown. `runCancellable` applies a caller-supplied step. If the stop function returns before a step, the result is the workbook that was saved before the pass, not a partly applied copy. The record names the dataset, the hardware string the caller supplied, the runtime, the version, and the elapsed time of that pass. An empty hardware string is stored as `not recorded`. A later completed pass on the same dataset, hardware, runtime, and version is a regression when it takes more than twice as long. The reason names the two times and does not repeat the dataset or the computer. A different computer is not a regression. A shorter pass is not called a speedup. A cancelled pass is not a regression. This elapsed time is the pass itself, not Univer recalculation, import, or painting. `importKeepingSaved` returns the saved workbook when stop is true before the imported file is kept. The loader may still finish, and that result is discarded. Opening an Excel file with a saved spreadsheet and a stop that is already true does not replace that spreadsheet. This does not interrupt the Excel parser in the middle of a file. While an import is running, Cancel import sets that stop. The loaded file is discarded. With a saved spreadsheet, that spreadsheet stays. Without one, the notice is `Import cancelled. The original file is unchanged.` and the file name is not in that notice. `timeWorkbookPhases` records load, parse, recalculate, render, serialize, save, and refresh separately. A phase with no function is skipped and is not given a measured time. Stopping skips the phases that have not started. A phase that throws is failed, and the error text is not stored. The return value of a phase is not stored, so a cell value used inside the phase is not part of the record. These times are the functions the caller supplied. They are not Univer recalculation, painting, or a speedup.

`expensiveFormulas` lists a formula that names at least 64 cells. `=SUM(A1:A80)` in C1 is `C1` with 80 cells. `=SUM(A:A)` counts as 10000 cells, so A1 is listed. A quoted `A:A` is not counted. `=SUM(1:1)` counts as 10000 cells. A quoted `1:1` is not counted. `=SUM(A1:B2)` still counts as 4 cells. `=A1` is left out. A quoted `secret-value` is not counted and is not in the list. This does not calculate the formula. The spreadsheet cost note says `Wide formulas: C1 names 80 cells.` or `No formula names 64 cells or more.` The formula text is not shown. The note was not opened in the browser.

A volatile formula is listed by its cell. `=NOW()` in B1 is `Volatile formulas: B1.` A quoted `NOW()` is not volatile. The formula text is not shown. The list is in column order, then row order. `TODAY()` in A2, `RAND()` in A10, and `NOW()` in B1 read `A2, A10, B1`. A10 does not come before A2. The note was not opened in the browser. This is not Univer recalculation. When the workbook has more than one sheet, the cell is named with that sheet. `NOW()` on Fees is `Fees A1`. A sheet name that is a credential is `another sheet`, and that name is not in the note. A sheet name that breaks across lines is `another sheet` as well, and the stored name stays.

`refreshQuery` checks a stop function before each step. Stopping returns the last saved rows, marks them stale, and does not keep the rows the unfinished steps would have produced.

A workbook of at most 50,000 stored cells is an interactive spreadsheet. From 50,001 through 200,000 cells it is in the large tier, and a query is the route when interactive editing no longer fits. Past 200,000 cells, recalculation, painting, and refresh do not start. A cell count that is not a whole number is refused and is not repeated. These counts are not a measured latency or memory budget. A sheet with no name is called Sheet, and the sheet id is not used. The cost note shows the sentence for the open workbook. In the large tier and past the spreadsheet limit, that note has Open the query panel. An interactive workbook does not. A cell value is not part of that sentence.

`cellsToRecalculate` can stop before it finishes. A stopped pass is `{ cells: [], unlisted: false, cancelled: true }`. That empty list is not a claim that no formula reads the changed cell. The formula text and the cell value are not in the result. The sheet passed in is not changed. This does not calculate the formulas.

A failed workbook phase skips the phases after it. When parse throws, recalculate is not called. The thrown text is not stored.
