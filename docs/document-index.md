# Document index

`refreshIndex` rewrites each index from text marks whose type is `index` and whose `term` is set. The first `Tomato` mark is `Tomato, section 1`. A later `tomato` mark is the same entry. `Paths` after a section break is `Paths, section 2`. The lines are sorted by the term. The rest of the sentence is not an index line, so `ready` and `north` stay in the paragraph and out of the index. Removing the Tomato mark drops that line. The document passed in is not changed.

A Word export writes those index lines into `word/document.xml`, with Paths before Tomato. The section number is the section that holds the first mark. It is not a printed page number. The document editor was not opened. Before the Word file is written, the index is rebuilt from the marks. A stale line `secret-value` is replaced by `Tomato, section 1` and is not in the file. The document that was exported still has the stale line. When the document stores page settings, the rebuilt line uses the printed page. A section break that restarts numbering at 5 lists the next term as `Paths, 5`. A restart that is not a page number continues the count, and that text is not an index line.

Passing the page settings uses the printed page instead. A file that starts at page 5 lists `Tomato, 5` on the first page and `Paths, 6` after a page break. A page break inside a note does not move Paths to the next page. The lines stay sorted by the term, so Paths is still first. The number comes from the same page start as the footer. When the file uses roman numerals, those lines are `Tomato, v` and `Paths, vi`. A Page N format writes `Page 5`. The index block itself is not a page of body text. A sentence that is not marked, including one that contains a secret, stays out of the index. The open editor was not measured.

A mark can also name a subentry. `Tomato` with subentry `North` is `Tomato, North, section 1`, and the plain `Tomato` mark stays `Tomato, section 1`. The sentence `secret-value` stays out of the index. A mark can also point at another term. `Beds` with see `Tomato` is `Beds, see Tomato`, with no section number. A term with a line break stays one index line, so `Tomato` and `beds` become `Tomato beds, section 1`. A term that is only an invisible character is left out. A term that starts with that character is listed without it, and a character inside the word stays. A see that is only that character is left off. The mark in the document stays as it was. A see that is only space is left off. A see that names the same term, including a different capitalization, is left off, so `Beds` with see `beds` is `Beds, section 1`. A see that names a term which is not marked says that the index term is missing. `Beds` with see `Paths` is `Beds, see Paths. That index term is missing.` A see that matches a credential word is not copied into that line. A see also keeps the page or section and names the other term when that term is marked. `Beds` with see also `Paths` is `Beds, section 1. See also Paths` when `Paths` is marked. A see also that is not marked says the index term is missing. A see also that matches a credential word is not copied into that line. The marked sentence stays out of the index. A term marked inside a note is indexed. A page break inside that note does not add a printed page. The other words in the note stay out of the index. The document passed in is not changed. Index entry writes that see mark on the selected words, and it can store a subentry. `Beds` with subentry `North` and see `Tomato` is `Beds, North, see Tomato`. A blank term is refused, and an entry that points at itself is refused. Those notices do not repeat the typed words. An empty selection is not marked. The document editor was not opened in the browser.
