# Bibliography import

`importBibtex` reads `@book` and `@article` entries. Each entry needs a key, an author, a title, and a year. Every editor is kept. `Priya and Sam` is two editors, and a name with a line break is left out. A DOI, URL, journal, volume, pages, and access date are kept when they are present. A key that matches a source already in the document updates that source and keeps its id, so an existing citation still points at it. Any other entry type is named and left out.

`exportBibtex` writes those fields back. The entry key is the citation tag. The import does not fetch a URL or a DOI. A source address that includes a credential is not stored. The notice says `That source address cannot include a credential.` and does not include the address. A DOI such as `10.1000/beds` is still stored. Saving the document and opening it again keeps the DOI, URL, journal, volume, pages, and access date. A BibTeX note is not stored.

A source may name several authors. One author stays `(Mensah, 2024)`. An author name with a line break is left out of the citation. `Priya` stays, so the citation is `(Priya, 2024)`. A source whose only author has a line break is cited as `(Unknown, 2024)`. The author field passed in still stores that name. Three authors are `Ada et al.` in the citation and `Ada, Lin, and Noor` in the reference list. A DOI on that source is not copied into either of those sentences. `bibliographyFull` adds it after the short entry as `https://doi.org/secret-value`. An access date `2024-03-01` is added there as `Accessed 2024-03-01.` The short list and the citation leave that date out. A date that is not a day, including `secret-value` and `2026-02-31`, is left out of the full entry. A journal, volume, and pages are added on that same full line, as `Garden Journal, 12, 4-9.` Pages stored as `12--4` are shown as `4--12`. The stored pages stay `12--4`. The short list and the in-text citation leave them out. The citation stays `(Ada et al., 2024)`. The source passed in is not changed. A source may also name several editors. The citation and the short list leave them out. The full entry adds `Edited by Priya and Sam.` A single editor that contains a line break is left out. The Word bibliography keeps the editors apart from the authors, and reading that list back keeps Priya and Sam. The Word bibliography lists each author, and reading that list back keeps all three. The source passed in is not changed. The Word file also writes the full line: `Garden Journal, 12, 4-9.`, `https://doi.org/10.1000/bed`, and `Accessed 2024-03-01.` The citation before that bibliography does not include the journal. An access date `secret-value` is left out of the Word file.

`importRis` reads the same fields from RIS. `JOUR` is an article and `BOOK` is a book. An ID that matches a citation tag updates that source. `exportRis` writes the fields back, with pages split into a start and an end. The import does not fetch a URL or a DOI.

`citationWarnings` lists a citation whose source id is not in the source list, with the path of that citation. A citation whose source is present is left out. The document is not changed. The message says to choose a source or remove the citation.

The citation panel has Import BibTeX, Download BibTeX, Import RIS, and Download RIS. A website can be imported from `@online` or an electronic RIS record. Its https address is stored and written back. An address that includes a credential is not stored. A file that is not a book, an article, or a website is shown in the panel and is not added. A reference-manager connection is separate. File → Export PDF writes an in-text citation, such as `(Rosa Garcia, 2020)`, into the PDF text. That file tags the citation paragraph as `P`. It is not a PDF/UA file.
