# Packaging

SuiteLeaf's editors are Apache-2.0. There is no fee in this repository for the software license. Hosting, storage, backups, support, and the assistant are listed separately. None of those has a price in this repository. "Not published" is not a quote.

Opening and saving a file on this computer does not require an account or a hosted bill. `cancelHostedService` stops hosted access. A file already on this computer stays in the local list. A file that exists only on the host is not copied here. No charge is added. The list passed in is not changed. The assistant stays off until it is turned on. Declining it leaves documents, spreadsheets, and slides able to open and save. Declining a storage expansion does not apply a charge, and files already on this computer stay readable. `expansionWarning` is the notice before that choice. It says extra hosted storage is optional, that this repository does not publish a storage price, and what happens if you decline. `applyExpansion` does nothing until that warning is acknowledged. A storage budget check says when hosted storage is near its budget or has reached it, and declining still applies no expansion. A count that is not a whole number of bytes is refused and is not repeated. No storage price is published. Acknowledging storage still applies no expansion and adds no charge. Acknowledging the assistant allows it to be turned on and adds no SuiteLeaf price. Settings and the cluster Admin page show that warning before Decline or Acknowledge. The pages were not opened in the browser.

`hostedHold` stops hosted access. A billing hold does not lock a file already on this computer: it still opens, saves, and exports. A security hold also leaves that local file readable and exportable, and it does not publish a grace period. A file that exists only on the host is not in the local list. The notice does not repeat a file title and does not publish a grace length or a price. The list passed in is not changed.

On the cluster Admin page, Download export saves accounts, groups, memberships, sharing, and a file list as JSON. An admin can also call `GET /api/admin/export`. The file list names each item, its kind, its owner, its folder, its type, whether it is in the trash, when it was created, when it was updated, and the current content hash. `Watering rota.sldoc` is in the folder `Plots`. `Watering rota.sldoc` records `bed-hash`. A file with no stored version has no hash. `Watering rota.sldoc` stays out of the trash. `Old notes.sldoc` is marked trashed. Passwords, session tokens, respond-link tokens, and file bytes are not included. The export does not require a paid feature. It does not copy the files themselves.

There is one software edition, SuiteLeaf, and its license charge is none. This repository does not publish a paid edition. Documents, spreadsheets, slides, and a slideshow on this computer run in the web app and in the desktop app, which loads that web app. They do not require an account or the assistant. Sharing through SuiteDrive runs on the web app, the desktop app, and the node, and it requires an account. The node does not paint the editors. The assistant is the only listed feature that requires the assistant. It runs in the web app and the desktop app, and it does not require an account.

The single-node Settings page includes this matrix under What SuiteLeaf includes. It lists the same cost categories and the web features. The text has no currency sign. The Settings page was not opened in the browser. A cluster library redirects away from Settings. The cluster Admin page includes the same matrix above the organization export. That page was rendered in a test and was not opened in the browser.

No commercial price should be added here without an explicit product decision.
