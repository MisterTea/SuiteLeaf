# Tables across pages

A table splits by row when the next row does not fit. The first row is the header. On a page of 4 lines, seven 1-line rows fill the first page with the header and three body rows. The next page repeats the header and then the other three body rows.

Without a repeated header, the second page starts at the fourth body row. The row heights passed in stay the same. A body row of 5 lines on a 4-line page stays on its own page after the header. It is not split in the middle of the row.

A section that is only a table uses this split for its page count. A two-row table still fits on one page. Two lines of text above the same seven rows leave room for the header and one body row, so the section takes three pages. A short Beds paragraph and a two-row table still fit on one page. A keep-with-next heading before a table moves with that table when the heading and the table fit on an empty page and the room left cannot hold both. An 80-row table after that heading is still more than one page. A 3-line paragraph marked for widow control, after 3 lines on a 4-line page, starts on the next page with the table. Without the mark it starts on the first page. The screen still measures the open document.
