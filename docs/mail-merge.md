# Mail merge batch

A header with space around it matches the placeholder, so ` Name ` fills `{{Name}}`. A header `name` also fills `{{Name}}`. A header that is only space is not a column. The header list passed in is not changed. `previewMerge` lists problems before any letter is written. A placeholder that is not a column is row 0. A placeholder whose cell is empty is that data row, counting from 1, and the column of that header. `Plot` in the second column of the first data row is cell `B2`. A column name that matches a credential word is not copied into that problem. The sentence says that name is not a column, or that the row has an empty cell. Empty data rows are skipped.

`mergeBatch` returns one document per remaining row. The name comes from the chosen column. A repeated name becomes `Rosa` and then `Rosa 2`, in row order, so the same rows always get the same names. `Ada` and `ada` are the same file name, so the second letter is `ada 2`. If the preview has any problem, no document is returned. The template object is not changed.

The merge dialog calls `mergeBatch`. Each row becomes its own document. The title is the template title, a dash, and the name. A name with a folder path keeps the remaining words: `../../secret-value` becomes `secret-value`, `Beds/North` becomes `Beds North`, and `../` becomes `Letter`. A column titled Name is used for that name; otherwise the first header is used. A preview problem is shown and no document is written. `mergeLetters` still builds one combined document for callers that want a single file.

`{{Planted|date}}` and `{{Fee|number}}` format an ISO date and a number for the document language. German uses `de-DE`. English uses `en-US`. Those two locales do not print `2026-10-31` and `1234.5` the same way. A date written `31/10` stays `31/10`. A date that is not a real day, such as `2026-02-31` or `2026-13-01`, stays as written. `{{Fee|currency:USD}}` formats 10 as `$10.00` in English. `currency:usd` is the same code. A date with a time, such as `2026-10-31T15:00:00Z` or `2026-01-15T23:00:00-05:00`, uses that written calendar day and does not shift the day. An hour past 23 stays as written. A time on a day that is not real stays as written. A currency code that is not three letters stays as written, and that code is not added to the letter. An unknown format stays as written. The template still contains the placeholders. The merge dialog passes the document language. It was not opened for this formatting.

`{{#Plot}}` keeps the text through `{{/Plot}}` only when Plot has text. `{{else}}` before the end is the text used when Plot is blank. `{{#Plot == North}}` keeps the first text only when Plot is North. `{{#Plot != North}}` keeps the first text when Plot is any other text, including `north`. A closing tag `{{/plot}}` matches `{{#Plot}}`. The unused side of that block is left out of the letter. A blank Plot leaves the first text out, including a value that was written inside the block. `{{#each Crop}}{{.}} {{/each}}` repeats the inner text once for each part of Crop separated by `;`. A blank part is skipped. `Tomato; ;Bean` becomes `Tomato` and `Bean`. The template text stays as written. A condition that names a column that is not in the sheet is the same missing-column error, and no letter is written. A blank Plot is not an error when the only use is that block, so the letter is still written and the hidden text stays out. A plain `{{Plot}}` that is blank is still an error and no letter is written. The merge dialog says a `{{#Plot}}` block is kept only when Plot has text, and that `{{#each Crop}}` repeats each part. The dialog was not opened in the browser for this check. Nothing is mailed. `mergePdfBatch` writes those same letters as text PDFs. A blank Plot leaves `secret-value` out of the first file. The second file contains `secret-value North.`. A blank plain field writes no PDF. This is not a print of the page and it is not a PDF/UA file. The merge dialog offers PDF beside Letters. Choosing it prepares one file per row. The status names the files and does not include the letter text. Nothing is mailed.

Labels use Avery 5160: 30 labels on a US Letter sheet, each 189 by 72 points. The 31st address starts the next sheet. An address taller than four lines is not clipped. Envelope #10 is 684 by 297 points. The return address and the recipient stay in separate boxes on the page. The merge dialog can place spreadsheet rows on those templates. Nothing is mailed. In the browser, Tools → Merge from a spreadsheet on an existing document showed Letters, Labels, and Envelopes. Labels drew the Avery sheet at 280 by 362 pixels. The library spreadsheet had no rows, so no address was painted on a label. Envelopes drew a 320 by 139 pixel sheet. The return address "Untitled document" and the recipient box stayed inside that sheet and did not overlap.
