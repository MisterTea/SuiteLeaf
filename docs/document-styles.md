# Document styles and captions

A named style has an id, a name, an optional parent style, and `bold` or `fontSize`. `effectiveFormat` walks the parent chain and then applies direct formatting. A direct property wins even when it is `false`. A parent cycle stops when an id repeats.

Captions carry their own ids. Figures and tables are numbered separately in list order. After one is removed, the rest are numbered again. A reference to a missing caption says `That caption is missing. Update or remove this reference.` The warning does not repeat the caption id. `captionWarnings` still keeps that id and the path, so the reference can be found. A missing id `secret-value` stays on the reference and is not copied into the warning or the refreshed sentence. A reference whose caption is still there is not listed. The document passed in is not changed. It does not invent a number.

The style list and the caption list are plain JSON, so a native save can store them. `applyStyleFormats` writes the resolved bold and font size onto text in blocks that name a style. A block's direct size stays. A block with no style id is left as it was. The input document is not changed.

A Word export reads `paragraphStyles` on the document and writes that resolved bold and font size onto the text. It also writes each style into `word/styles.xml` under its id and name, and the paragraph refers to that id. A style based on another uses that parent id. A direct size of 16 stays 16 on the paragraph. An id that is not letters and digits is left out of the style part. Opening the document applies the same list. A document with no list is left as it was. `updateNamedStyle` stores a new size on that style and writes it onto the paragraphs that use it. A paragraph that already stores 16 stays 16. Tools → Named styles sends that size. Match the selection stores the selected words' bold setting and point size on the style. The words are not copied onto the style. A paragraph that already stores its own bold or size keeps them. A size written as something other than 1 to 96 points is left out. No selection says `Select the words to match.` Use this style points the current paragraph at the chosen style and writes that bold and size onto its text. A paragraph that already stores its own bold keeps that choice. An unknown style id leaves the paragraph as it was. An unknown style id leaves the list at 18. `importParagraphStyles` adds a style the document does not already have. A template heading of 22 does not replace the document heading of 18. A new Note style of 14, based on that heading, is stored, and its paragraph becomes 14 points and bold. A paragraph that already stores 16 stays 16. A size of 0 is left out, and a parent that was left out is not stored. The document passed in is not changed. A template that only repeats styles already on the document does not write marks. The document editor was not opened in the browser. Tools → Named styles can import a template file. A file with Note at 14 adds that style and leaves Heading at 18. Text that is not JSON says the file is not a style template, and the file text is not shown.

A document with a section break numbers figures and tables again in each section, as `Figure 1.1` and `Figure 2.1`. A document with no section break still uses `Figure 1`. `refreshReport` rebuilds the contents field and those lists together. The Word file contains the contents lines, the section figure lines, and the author and keywords from the file properties. The input document is not changed.

`refreshCaptions` rebuilds a figure or table list from the captions still in the document. After the Beds figure is removed, the figure list is `Figure 1 Paths` and a reference to Beds is the warning that names `fig-a`. A reference to Paths becomes `Figure 1`. A table caption stays out of a figure list. The Word export of that rebuilt list contains those lines. The export also rebuilds a stale list before it writes the file. A document that still says `see Figure 9` exports `Figure 1 Paths` and `That caption is missing. Update or remove this reference.` The open document still says `see Figure 9`. The input document is not changed. A caption inside a note stays out of the figure list. A reference inside that note to a caption in the body is still rewritten. A caller can supply a whole page number for a caption. Figure 1 Beds on page 2 is `Figure 1 Beds, 2`, and Figure 2 Paths on page 4 is `Figure 2 Paths, 4`. A page that is not a whole number is left off, and that value is not written. The editor does not supply those page numbers yet. A Word export that stored page settings and left page numbers on writes them. Beds before a page break and Paths after it export as `Figure 1 Beds, 1` and `Figure 2 Paths, 2`. A table list does the same: `Table 1 Harvest, 1` and `Table 2 Paths, 2`. The caption ids are not in the file. Turning page numbers off leaves the page off the list.

`refreshHeadingRefs` rewrites a heading reference to that heading's text. A reference to `paths` becomes `Paths`. A figure list names a caption of only invisible characters as `Figure`, and a table list names that caption as `Table`. The caption id is not in the list. A heading with no title says that heading has no title. A heading that is only an invisible character says the same. A heading that starts with that character is referenced as `Beds`, and a character inside the word stays. The heading in the document stays as it was. A missing id stores `That heading is missing. Update or remove this reference.` and does not repeat the id. `refreshReport` does this when it rebuilds the contents field and the figure and table lists. The contents line is `Section 1: Paths`. A heading that is only an invisible character is not a contents line. A heading that starts with that character is listed without it, and a character inside the word stays. The heading in the document stays as it was. A heading inside a note is not a contents line. A heading reference also leaves that note heading out, so the reference says the heading is missing. A reference inside the note to a body heading still becomes that heading's text. The note heading stays in the note. When the document numbers pages, a heading before a page break is `Section 1: Beds, 1` and the next heading is `Section 1: Paths, 2`. A section break that restarts numbering at 5 lists the next heading as `Section 2: Paths, 5`. The contents field in the editor uses that same number, and a measured page keeps it. A figure list in the editor does too. A restart that is not a page number continues the count, and that text is not a page number. The heading id is not in that line. Turning page numbers off leaves the page off. A Word export does this before it writes the file. Before the page is measured, the contents field in the editor uses the same page-break count: the heading before a page break is page 1 and the heading after it is page 2. A measured page replaces that number. The heading text is not stored in that page list. A figure list in the editor uses the same page-break count. A page break inside a note does not change that count. A caption before a page break is page 1, and a table caption after it is page 2. The caption id is not in that list. The Insert menu has Figure list and Table list. Inserting a table list stores that kind. The document editor was not opened for this list. The reference becomes `Paths`, and a missing id is the same warning. The input document is not changed.

A document can store `properties` with an author, a subject, keywords, a description, and a category. Those fields are on the file, not in the body. Undoing the body restores the earlier text and leaves the properties in place. Redoing the body restores the later text and still leaves them. Saving the file as JSON and reading it back keeps the same author, subject, keywords, description, and category. A Word export writes the author, subject, keywords, and description into `docProps/core.xml`, and the category into `docProps/custom.xml`. `refreshContents` rebuilds a contents field from the headings in each section. A heading after a section break is listed with the next section number. A heading deeper than the field's level is left out. After the Beds heading is removed, the list is `Section 2: Paths` and `Section 2: Detail`. The Word file contains those lines in that order and still contains a contents field. The input document is not changed.

A character style named Emphasis that is bold and italic adds those marks to a run marked with that style. A direct choice to leave bold off keeps italic and drops bold. A style id that is not in the list stores `That character style is not in this document.` and does not repeat the id. The run text stays, and the document passed in keeps its original marks. Tools → Named styles lists a character style stored on the document and Use character style applies it to the selection. Emphasis is bold and italic. An id `secret-value` is left off that list. Emphasis can be based on Strong. Strong is bold, so the run is bold and italic. Setting bold off on Emphasis leaves only italic. Reading that style list back keeps bold off, so the run stays italic only. A parent id `secret-value` is left off the stored style. A cycle between the two styles still finishes. `importCharacterStyles` adds Emphasis from a template when the document does not already have it, and leaves Strong as it was stored. A parent that is not in either list is left off. An id `secret-value` is not stored. The run text stays. The document editor was not opened in the browser.
