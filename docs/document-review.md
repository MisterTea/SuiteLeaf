# Document review

`reviewCombine` compares two reviewers' copies with a shared baseline. An edit that only one reviewer made is kept. When both reviewers change the same block to different text, that block stays as it was in the baseline and the result lists a decision. The decision names the block number and the reviewers. It does not copy the block text. A reviewer name that looks like a credential is called `a reviewer`. The copies passed in stay as they were. Choosing the left or the right copy replaces that one block. The other decisions stay. A block that does not need a choice is left as it was. A block number that is not a whole number at or above 1 says `Name a block number.` Undoing the latest choice puts that block back and leaves earlier choices in place. Undoing when nothing was chosen says `There is no choice to undo.`

`approveDocument` stores one revision. `readApproved` returns that copy. Editing the document keeps the approved copy and makes the current revision unapproved. An unchanged document stays approved. A revision named like a credential says `Name a revision.` and that name is not stored. `writeReview` stores the decisions, the choices, and the approved revision name on the document. `readReview` reads them from a saved copy. A note that looks like a credential is stored as `Block N needs a choice.` The paragraph text stays. A Word file can carry the same review in `word/suiteleaf-review.json`. Opening that file in SuiteLeaf puts the review back on the document. The editor's Word download adds that part when the document has a stored review. A shared document keeps the review on the room, next to the paragraph text. The open document copies that review onto itself, and an edit of the review is copied back. A review value that is not a review is left out. Original shows the baseline. Final shows the current document. Markup marks each block that differs. A removed block is marked removed and its text is left out. This is not an e-signature. The document editor was not opened.
