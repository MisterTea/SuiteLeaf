# Formula audit

`auditFormula` lists the cells a formula reads and the formulas that read it. `A1` with `=B1`, and `B1` with `=A1`, is a cycle: `A1 refers to B1, and B1 refers to A1.` The trace says each of those reads. A stored error code such as `#CYCLE!` is named with the cell. Any other cell value is left out. A cycle through `A1`, `B1`, and `C1` says `A1 refers to B1, and B1 refers to C1, and C1 refers to A1.` A formula `="secret-value"` is not in that result. The sheet passed in is not changed. A reference to another sheet stays on that sheet. `=Fees!B2` reads `Fees!B2`, not `B2` on this sheet. A sheet name with a hyphen works the same way: `=Plot-Fees!B2` copies that cell. The sheet name is matched without regard to capitalization, so `=beds!A1` reads the sheet named `Beds`. When `Fees!B2` reads `Beds!A1`, the cycle is `A1 refers to Fees!B2, and Fees!B2 refers to A1.` The cell value is not in that sentence. Changing `Beds!A1` copies that value into `Fees!B2` when the formula is `=Beds!A1`, and then into the next formula on Fees. `=SUM(Beds!A1:B1)` on Fees becomes 15 when those cells are 10 and 5. A space after the equals sign is still calculated, so `= SUM(Beds!A1:B1)` is also 15. The evaluation trace does the same for `= SUM(A1:B1)` and `= B1`. `=AVERAGE(Beds!A1:B1)` becomes 15 for 10 and 20, and a blank cell is skipped, so 10 and a blank cell average to 10. The address list does not include 15. Text in that range leaves the previous value in place. The address list does not include the value. A cycle across the two sheets is left unchanged. The formula audit panel names that other sheet and does not show the value. The next error can be on another sheet. After `B1` on this sheet, the next error on Fees is `Fees!A2`. A sheet name that is a credential word is called `another sheet`, and that name is not in the note.

A range larger than 64 cells is named and not expanded. The sheet passed in is not changed. This pass does not calculate the formula.

`evaluationTrace` explains a direct reference or a sum of at most 64 cells. `A1` of `10` and `B1` of `5` make `The sum is 15.` Text is named as text and is not copied, and that sum is not calculated. A wider sum is not traced. The formula text is not in the sentence. The sheet passed in is not changed.

`=COUNT(Beds!A1:C1)` becomes 2 when one cell is 10, one cell is text, and one cell is blank. The count does not copy the text. The evaluation note says `The count is 2.` A cell whose value is `#DIV/0!` is named that way, and a sum that reads it is not calculated. The formula text is not shown. A formula that sums a range on another sheet names each cell. `=SUM(Fees!A1:B1)` with 4 and 5 says `Fees!A1 is 4. Fees!B1 is 5. The sum is 9.` A sheet whose name is a credential word is called another sheet, and text in that range is not copied. A formula that copies one cell on another sheet names that sheet and cell. `Fees!B2` holding 9 makes the note `A1 copies Fees!B2. B2 is 9. A1 is 9.` A sheet name that is not in the workbook, when that name is a credential word, is left out of the note. `=MIN(Beds!A1:C1)` is 4 and `=MAX(Beds!A1:C1)` is 10 when the cells are 10, text, and 4. The text is skipped. A range with only text is left as it was, and the note says the minimum was not calculated. `=ROUND(A1, 2)` of 1.239 says `A1 is 1.239. The rounded value is 1.24.` `=ROUND(-1.5, 0)` says `A1 is -1.5. The rounded value is -2.` A halfway value rounds away from zero. `=ROUND(A1, B1)` uses the number in B1, so 2 places says `A1 is 1.239. B1 is 2. The rounded value is 1.24.` Text in that digit cell is not copied. The note names the number and says the digit cell is text. Text is not rounded, and the formula word is not in the note. `=IF(Beds!A1, Beds!B1, Beds!C1)` on another sheet uses C1 when A1 is 0, so the result is `Beds`, and the unused cell stays unused. `=ROUND(Beds!D1, 2)` of 1.239 becomes 1.24. Text in the condition stays at the previous value. The address list does not include that text. A choice between two cells uses the third cell when the first cell is 0, and the second cell otherwise. `A1` of 0, `B1` of text, and `C1` of 4 says `A1 is 0. C1 is 4. The result is 4.` Text in the condition is not copied, and the result is not decided. `=ABS(A1)` of -4 becomes 4, and the note says `A1 is -4. The absolute value is 4.` Text is not copied, and that absolute value is not calculated. `=ABS(Beds!A1)` of -3 becomes 3. The formula word is not in the note. `=AND(A1, B1)` with 2 and 0 says `A1 is 2. B1 is 0. Both are not true.` Text is not copied, and both are not decided. `=AND(Beds!A1, Beds!B1)` with -4 and 3 says both are true. `=OR(A1, B1)` with 0 and 3 says `Either is true.` Both zeros say `Neither is true.` Text is not copied.

`=TRIM(A1)` of `  Beds   North  ` says `A1 is text. The trimmed text has 10 characters.` The text is not copied. `=TRIM(Beds!A1)` of `  Beds  ` says the trimmed text has 4 characters. `=LEN(A1)` of -4 says `A1 is -4. The length is 2.` Text says `A1 is text. The length is` and the number of characters, and the text is not copied. `=LEN(Beds!A1)` of `Beds` says `Beds!A1 is text. The length is 4.` `=NOT(A1)` of 0 says `A1 is 0. The opposite is 1.` A number other than 0 says the opposite is 0. Text says `The opposite was not calculated.` and the text is not copied. `=NOT(Beds!A1)` of 3 says `Beds!A1 is 3. The opposite is 0.`

`=IF(A1>10, B1, C1)` uses B1 when A1 is greater than 10 and C1 otherwise. `=IF(A1="beds", "Yes", "No")` matches text without regard to case. Text ordered against a number stays at its previous value. The note says `The comparison is true. The result is 4.` or `The comparison was not decided.` It does not include the formula word or the text. A comparison on another sheet uses that sheet's cells. `=AND(A1>10, B1<5)`, `=OR(A1>10, B1<5)`, and `=NOT(A1>10)` use the same comparison. `=IFS(A1>10, B1, C1<5, D1)` uses the value beside the first true comparison. A test that is not a number stays at its previous value. The note says `Both are true.`, `Either is true.`, `The opposite is 0.`, or `The first true test uses 4.` It does not include the formula word or the text. `=COUNTIFS(A1:A3, ">10")` counts numbers greater than 10. `=COUNTIF(A1:A3, ">10")` does the same. `=SUMIF(A1:A3, "Pass", B1:B3)` and `=SUMIFS(B1:B3, A1:A3, "Pass")` add the amounts beside `Pass` and `pass`. `=AVERAGEIF(A1:A3, "Pass", B1:B3)` averages those amounts. Text is not counted by a numeric criterion. The note says `The count of matching cells is 1.` and does not include the text. `=IFS(A1>10, "High", TRUE, "Low")` uses `High` when A1 is greater than 10 and `Low` otherwise. The note says `The first true test uses text.` and does not include that word.

The spreadsheet toolbar button Audit shows that note for a cell address. Next error moves from `A1` to `B1` when `B1` is `#DIV/0!`, then to `D1` when that cell is `#VALUE!`. From `D1` it returns to `B1`. A cell whose value is not an error code is skipped. The only error on the sheet you are already viewing says there is no other formula error. The painted grid is not required to type the address. The panel was not opened in the browser.
