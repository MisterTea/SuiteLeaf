# Reference workflows and v1 coverage

The local books are workflow references. The implementation uses independent code and original sample content. This document records the relevant sections reviewed and how those workflows inform v1, rather than claiming the whole library is a complete product specification.

| Reference | Relevant material | SuiteLeaf v1 |
| --- | --- | --- |
| *Google Workspace For Dummies*, Paul McFedries (2024), chapters 5–7 | Creating/naming/copying documents; editing; finding/replacing; text/paragraph formatting; images and tables | File library, Docs editor, formatting toolbar, outline, table controls, image uploads, native and simple exports |
| Same book, chapter 8 | Creating spreadsheets; cells and ranges; data entry; formatting; row/column operations | Univer grid, worksheet tabs, formatting, navigation, ranges, freezing, and row/column tools |
| Same book, chapter 9 | Operators/references/functions; sorting/filtering; charts; pivot grouping and aggregation | Formula engine, sort/filter packages, embedded Recharts charts, Arquero pivot worksheets |
| *Ultimate Guide to Google Sheets*, local Kenneshaw PDF, chapter 1 | Create/fill a sheet; format data; aggregate values; move data | Sample budget, grid editing, formulas, CSV/TSV/native portability |
| Same guide, chapters 5 and 8 | Reporting dashboards, templates, organizing files, backups | Charts/pivots, original sample workbook, searchable local files, portable native copies |
| *Teach Yourself VISUALLY Google Workspace*, Guy Hart-Davis | Visual organization of document and spreadsheet workflows | Familiar menus, toolbars, writing canvas, grid, and worksheet navigation with SuiteLeaf branding |

## Acceptance scenarios

1. Draft a short report, apply headings and emphasis, add a table and image, use find/replace, reopen it, and print/export it.
2. Enter a budget with category names and numeric values, calculate totals and remaining amounts, sort/filter the data, and reopen it with formulas intact.
3. Build a chart from a headered range, change its data, resize it, and reopen its definition and placement.
4. Group a dataset using a pivot worksheet, filter a field, refresh after a source change, and make an editable copy.
5. Move a native file between browser and desktop; recover edits after restart and retain them when the disk file changes externally.

Collaborative chapters, Google-specific AI/functions, DOCX/XLSX export, live page layout, and other Workspace applications are outside v1. They are not represented as working features in the interface.

DOCX/XLSX loading is now supported. The document-management sections inform editable imports, native copies, original-file preservation, save/reopen checks and explicit compatibility notes. See [Office import coverage](office-imports.md) for conversion limits and measured corpus results.
