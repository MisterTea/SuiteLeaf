# Sheet queries

A query document is version 1 and a list of steps: `select`, `rename`, `filter`, `sort`, and `dedupe`. `sort` orders one column. Plain numbers use numeric order, so `2` comes before `10`. Other text uses text order. A blank cell, including spaces only, stays last whether the order is A to Z or Z to A. Equal values keep their original order. The source rows stay as they were. A missing column says `That column is not in the source.` and does not repeat a credential-like name. `dedupe` keeps the first row for a column value and drops later rows with that same value. Two Tomato rows keep the first note `kept` and drop the second note. A plot written `10` and `10.0` is the same value, so the first row stays `10` and the later row is dropped. `north` stays its own row. A missing column keeps the last rows and marks them stale. The error names the column and does not include the dropped note. The source rows stay as they were. `group` sums or counts rows that share a value, in the order that value first appears. North amounts `10` and `5`, plus a non-numeric amount, sum to `15`. The non-numeric amount is not copied into the result. The average of those two numbers is `7.5`. The non-numeric amount is left out of the average and is not copied into the result. A group with no numbers is blank. The smallest of North's numbers is `5`, and the largest is `10`. A plot written `10` and `10.0` is one group, labeled `10`, and those amounts add. `north` stays its own group. A group with no numbers is blank for both. The query panel lists Minimum and Maximum. A missing group column keeps the last rows and marks them stale. `split` divides one column on a separator into named columns and drops the original column. `North, Tomato` becomes bed `North` and crop `Tomato`. A value that does not have that many parts keeps the last rows, marks them stale, and the error does not include the cell value. `join` copies named columns from a lookup table supplied at refresh time. The lookup is not stored on the query. The first matching row is used. A later North note and a West note that do not match a source row are not copied. A refresh without the lookup keeps the last rows and says a join needs a lookup table. `append` stacks that same supplied table after the source rows. The extra row is copied, including its note. The query document does not store those rows. A refresh without the table keeps the last rows and says an append needs another table. A query that both joins and appends uses one supplied table for both steps. `merge` joins named columns with a separator into one column and drops the columns that were merged. `bed` `North` and `crop` `Tomato` become `place` `North, Tomato`. The note stays. A missing column keeps the last rows, marks them stale, and the error names the column rather than the cell value. `convert` checks a column as a number, text, or an ISO date. `010` becomes `10`. `2026-10-31` stays. `2026-02-31` is not a date. A value that is not a number keeps the last rows, marks them stale, and the error does not include the cell value. The source cell stays as it was. Running it copies the source rows, applies each step, and returns the rows with the time of that refresh. The same document and the same source produce the same rows. A spreadsheet can store that document. Reading the file back returns the same steps, and a refresh then returns the same Tomato row. The source rows are not stored on the query. A successful refresh from the query panel stores that filter on the spreadsheet as `selection`. Opening the panel again shows the saved column and value. The panel can also join or append a range on the same sheet. A join on `bed` copies the first North note `kept` and does not copy a later North note or a West note. An append stacks the extra row, including its note, under the selection. The saved join step keeps the range `E1:F4`. The saved append step keeps `E1:F2`. The source cells stay. The spreadsheet was not opened in the browser.

`reviewQuerySchema` names a step whose column is not in the header list. A rename of `bed` to `plot` lets a later filter use `plot`. A later sort of `gone` is step 3. The note does not include a cell value. Check columns on the query panel uses the header row and does not write the sheet. Use this column instead rewrites the step from the old column name to the new one. `crop` becomes `plant`. A credential-like name is refused and is not shown. The spreadsheet was not opened in the browser.

A filter can store `{{plot}}` instead of a value. Refresh with `plot` set to `North` keeps the North row and drops a bed named `secret-value`. The saved step still says `{{plot}}`. A refresh with no value says `Name the value for plot.` and does not repeat a cell. The query panel has a Parameter field. A name `plot` and a value `North` save `{{plot}}` and keep the North row. The value is not stored. A parameter named `secret-value` is refused, and that word is not in the message. A filter with `match` `ne` keeps every row whose column is not that value. Tomato is dropped and South stays. The source row stays Tomato. Exclude this value on the query panel stores that match. A filter with `match` `contains` keeps a row whose column includes that text. `beds` keeps `Water the beds` and drops a different crop. A blank search keeps only a blank cell. A filter for `10` also keeps `10.0`. `north` stays out of that filter. Exclude `10` drops both of those numbers and keeps `north`. The source cell stays `10.0`. The query panel has Cell contains this text.

If a stop function returns before a step, the refresh keeps the last saved rows and marks them stale. It does not keep a partial result. If a step names a column the source no longer has, the refresh fails. When a previous successful result was passed in, that result is returned again and marked stale. The source array is not modified. `remapQuery` rewrites only the column names the caller maps, such as `crop` to `plant`, and then a refresh can succeed. A name that is not in the map stays, so the old query still fails instead of dropping that column. An empty name or a credential-like name is refused with `That column cannot be remapped.` The refusal does not include the column name or the rejected name. The document passed in is not changed. A field whose name looks like a credential is refused with `A query cannot store a credential.` The refusal does not include that field name or its value.

`queryDocument` rejects an extra field whose name looks like a password, token, or API key. The document type has no place to store one.

`writeQueryOutput` copies a successful result into a cell grid. The first row is the column names. Cells inside the previous output rectangle may be replaced, and cells that the new result no longer uses are cleared. A cell outside that rectangle that already has a value stops the write, and the grid is not changed. A failed refresh does not write, so the last successful cells stay.

`refreshGridQuery` reads a header and the rows under it, runs the saved steps, and writes the result at another origin. The source cells stay. A failed refresh does not write.

The spreadsheet toolbar button Query filters the selection. The column name and the value to match are typed in the panel. Matching rows are written one blank column to the right of the selection. A destination cell that already has a value stops the write. The same panel can convert one column. `010` written as a number becomes `10` beside the selection. A value that is not a number is not written, and the message does not include that value. The source cells stay. The saved step is the conversion, not a filter. The same panel can sort the selection. Plain numbers sort as numbers, so `2` comes before `10`. Z to A on `crop` writes Tomato before Bean. The Bean note stays with that row. The message does not include the note. A missing column is not written, and the error names that column. An empty name says to name the column to sort. The source cells stay. The same panel can drop duplicate rows. Two Tomato rows keep the first note `kept` and drop the second note. The message does not include that note. The source row stays. A missing column is not written. An empty name says to name the column to check for duplicates. The same panel can group rows. North amounts `10` and `5`, plus a non-numeric amount, sum to `15`. South is `3`. The message does not include the non-numeric amount. The source row stays. A missing column is not written. An empty group name says to name the column to group by. The same panel can split one column. `North, kept` becomes bed `North` and note `kept`. A row that does not have that many parts is not written, and the message names the source column. An empty name says to name the column to split. The same panel can merge columns. Bed `North` and note `kept` become `North, kept`. A missing column is not written, and the message names that column. Fewer than two columns says to name at least two columns to merge. `refreshRemoteQuery` asks the caller to fetch one https address and then runs the saved steps on those rows. A view that is not allowed does not fetch. A protected source is not fetched for a viewer or for someone with no access, even when the view itself is allowed. An owner or an editor still fetches it. The error does not include a cell value. An address that is not https is not fetched. A failed fetch, or a table that no longer has a column the steps name, keeps the last rows and marks them stale. The error does not include the response body. The address is not stored on the query document. `runScheduledRefresh` fetches only when that address is due. The interval is at least one minute. An earlier call does not fetch and does not mark the last rows stale. A view that is not allowed does not fetch, leaves `lastRunAt` unset, and keeps the last rows marked stale. A fetch that fails still moves `lastRunAt` forward and keeps the last rows. This function does not start a timer. `runScheduledBatch` runs several due refreshes, at most four at a time. A source that does not answer is tried once more. Stopping after one refresh leaves the later jobs unfetched and names them as cancelled. The notice names the job, such as `Beds was refreshed.`, and does not include the address. This function does not start a timer. `refreshDatabaseQuery` sends one statement that starts with `SELECT` and contains no semicolon and no statement that changes data. Anything else is not sent. A view that is not allowed is not sent. A protected source is not sent for a viewer or for someone with no access. A driver error is replaced with a fixed sentence, so a password in that error is not shown. The last rows stay and are marked stale. The statement is not stored on the query document. This does not open a database itself.

A scheduled refresh can stop waiting. One second with no answer becomes `The source took too long.` The last rows stay. The notice does not include the address. A limit that is not a time becomes `The refresh limit is not a time.` and the source is not fetched. `runScheduledRefresh` itself does not start a timer. The query panel does. Refresh on a schedule reads the source after each whole minute the field names, and Stop scheduled refresh clears that wait. Rows that arrive after Stop are not written. Starting the schedule stores the wait and the https address on the spreadsheet. Stopping removes that record. Opening the panel fills those fields and does not fetch until Refresh on a schedule is chosen again. A credential address is not stored. A source token is sent with the request as `Authorization: Bearer` and is not written on the spreadsheet. The refresh notice does not include the token.

`rowsFromCsv` and `rowsFromJson` read a local table. A leading byte-order mark is ignored, so the first column is still `bed`. A quoted comma stays in the field. A JSON value that is not text, or a file that is not a table, says `That file is not a table of text.` and does not repeat the file. `refreshLocalQuery` runs the saved steps on that table. The file text is not stored on the query document. A bad file keeps the last rows and marks them stale. The query panel has a Local table file control. A file that is not a table says `That file is not a table of text.` and does not repeat the file name. A table of two rows says `The table has 2 rows.` and does not repeat a cell. A destination that already has a value is not overwritten, and the status says `A cell already has a value.` The spreadsheet was not opened in the browser.

An https address that includes a user, a password, a query name such as `token`, a path segment such as `token`, or a fragment such as `api_key` is not fetched. The notice is `The source address cannot include a credential.` and does not include the address. A scheduled refresh with that address is not due. The query panel shows that notice and does not fetch. An `http` address is still `The source address is not https.`

A date conversion keeps a calendar day written with a time. `2026-10-31T15:00:00Z` becomes `2026-10-31`. `2026-01-15T23:00:00-05:00` becomes `2026-01-15`. A day that is not on the calendar, including `2026-02-31T00:00:00Z`, keeps the last rows and marks them stale. The notice is `Column planted is not an ISO date.` and does not include the cell. The source cell stays as it was written.

A missing column, a value that is not a number, and a value that is not a date name the column. When that name is a credential, the notice says `That column` and does not include the name. A split that does not produce the named number of parts keeps the last rows. `North, Tomato` split on a comma into bed and crop becomes `North` and `Tomato`. A cell that is only `North` says `Column place does not split into 2 parts.` A column whose name is a credential says `That column does not split into 2 parts.` and that name is not in the notice. The source cell stays as it was written.

A join does not match a blank key. A source row with an empty bed stays empty even when the lookup has an empty bed. A North row still takes the first North note. Two plain numbers use the same key, so a bed `10` takes the note from a lookup bed `10.0`. The source cell stays `10`. `North` does not match `north`.
