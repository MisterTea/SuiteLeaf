# Proofing language

A document stores a proofing language with its other proofing settings. The choices are English, Spanish, French, German, Arabic, and Hebrew. A missing or unknown value is English. A slide text box uses that language's writing direction. Arabic and Hebrew are written from right to left. English is written from left to right. The spreadsheet cell text fields use the same direction. The painted grid was not changed. A slide comment pane uses that direction too. The dictionary and word count use that language's writing direction. The spelling dialog uses the same direction. Comments in the document margin use that language. Comments stored beside a document, spreadsheet, or presentation use that file's language. A form or drawing stays left to right.

A grammar suggestion includes a local explanation. `they was` says a plural subject takes were. `a hour` says to use an before a vowel sound. The explanation does not include the rest of the sentence, and the sentence is not sent off this computer. The grammar panel shows that explanation. It was not opened in the browser. A word written twice, `the the`, is one issue. The suggestion is the single word `the`, and the explanation is `This word is written twice.` A period between the words is not that issue. One occurrence of `secret-value` is not an issue, and that word is not in the doubled-word result. Ignoring `repeated the` leaves the pair alone. The sentence is not sent off this computer.

A spelling suggestion includes a local explanation that does not repeat the typed word. `teh` to `the` says two letters are swapped. `movment` to `movement` says a letter is missing. `cat` to `cot` says one letter differs. `secret-value` compared with `secret` says two changes are needed, and that sentence does not contain `secret`. The spelling dialog shows the explanation when the chosen word is one of the suggestions. The dialog was not opened in the browser.

English spelling uses the dictionary already on this computer. The text is not sent to a spelling service. Another language is not compared with that English word list, so a Spanish word is not underlined as an English mistake. A word the reader flags is still underlined, and a word they add is still accepted. There is no local dictionary for those other languages, and this does not claim grammar or spelling quality for them. A text range can store its own language. Inside a Spanish document, an unmarked `recieve` is left alone, a Spanish range `camas` is left alone, and a range marked English still flags `recieve`. A language value that is not one of the five choices is ignored. The spelling dialog can apply the chosen language to the selection. The dialog was not opened in the browser.

A spreadsheet can store Spanish, French, German, Arabic, or Hebrew. Those cells are not compared with the English dictionary, and the text is not sent to a spelling service. A word the reader flags is still marked. An Arabic word can be remembered for Arabic, and a flagged Arabic word is still found. It is not compared with the English dictionary. Arabic and Hebrew are written from right to left. The other proofing languages stay left to right. The document editor sets that direction from the document language. A slide deck can store the same languages. A Spanish title is not compared with the English dictionary. A flagged word is still marked. The slide canvas was not opened in the browser. The assistant does not rewrite a document that is not set to English.

A word can be remembered for one language. `secret-value` remembered for Spanish stays on that list, and the notice does not repeat it. English still flags `recieve`. Remembering `recieve` for English stops that flag. Two words are refused with `Remember one word.` and are not stored. The text is not sent to a spelling service. The spelling dialog was not opened in the browser. The underline check skips `recieve` when it was remembered for English, and still lists it when that word was remembered only for Spanish. The document was not opened in the browser.
