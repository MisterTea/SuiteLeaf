# Forms

`formResponseRows` writes an authorized export. The header names each question as `id@version`. A question id or version that looks like a credential is `question 1`. An answer that starts with `=`, `+`, `-`, or `@` is text, with a leading quote. A repeated response id is kept once. The notice does not include that id. The lists passed in stay as they were.

A response id that is already stored is not added again. The first answers stay. On the node, a responder who sends that id a second time is refused, and the saved form still has the first answer. This is one node, not two nodes writing at once. A responder who reads the form gets the questions and an empty response list. The owner still reads the stored answers. A responder search for an answer does not find the form. A search for the question still finds it, and the snippet does not include the answer. The owner search still finds the answer. A responder cannot save a response that leaves a required question blank. The refusal names the question, `Plot is required`, and does not include the other answer. The first response stays. A form with `accepting` set to false does not take another response. The refusal is `This form is not taking more responses.` The sign-up link uses that same check. The public form says it is not accepting, the submission is refused, and the answer is not stored. A missing `accepting` field still takes responses. A choice can skip later questions. `Large` jumps to the note and does not keep the beds answer. `Small` still requires beds. The sign-up page hides the skipped question. A question can be worth points. The score counts only the questions that were shown. The correct answer is not on the public sign-up form. A sign-up that matches the shown answers stores `score` and `possible`. A file question stores the file name and size, not the file bytes. `Beds.png` of 12 bytes is `Beds.png (12 bytes)`. A script, a path, a credential-like name, or a file over 5,000,000 bytes is refused, and the name is not in the refusal. A number question keeps `4` inside 1 to 10. `secret-value` says `Enter a number.` and that word is not in the refusal. `11` says `That number is outside the range.` The public form includes the minimum and maximum. A deadline of `2020-01-01T00:00:00.000Z` refuses another response with `The deadline for this form has passed.` A deadline that is not a time does not close the form. A deadline in 2099 is still open.

This is not a public form payload. A form was not published.
