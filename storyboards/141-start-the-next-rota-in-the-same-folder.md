# 141 · Start the next rota in the same folder

**Mode:** cluster · **App:** Files · **Video:** [videos/141-start-the-next-rota-in-the-same-folder.mp4](videos/141-start-the-next-rota-in-the-same-folder.mp4) · **Script:** [scenes/141-start-the-next-rota-in-the-same-folder.spec.ts](scenes/141-start-the-next-rota-in-the-same-folder.spec.ts)

## Who and why

Rosa is editing the watering rota inside Garden club. Next month needs its own copy, and she also wants a blank note beside it. In Google Drive, Make a copy opens a folder dialog she has to confirm, and a new file from the editor can land somewhere else. In SuiteLeaf, File › New and Make a copy always put the file at the top of My Drive, so the club folder looks empty of the thing she just made.

## Inspired by

- Storyboard [23](23-start-a-document-in-suitedrive.md): New and Make a copy from the editor start at the top of My Drive.
- Storyboard [140](140-put-the-rota-in-the-club-folder.md): the open file shows its folder, and Move can change it.
- [Make a copy of a file](https://support.google.com/docs/answer/49114): the copy dialog asks for a folder. The default is easy to miss, and the new file is not obviously in the same place.

## Scenes

1. **Inside the club folder.** Rosa is signed in and opens Watering rota. The control next to the title says **Garden club**.
2. **Make a copy.** She chooses File › Make a copy. No folder dialog appears. The copy opens, and the control next to its title still says **Garden club**.
3. **Both files are there.** She clicks **Garden club**. The folder lists the rota and the copy. My Drive lists neither.
4. **A new document.** She opens the copy and chooses File › New document. The new file opens with **Garden club** next to the title. The folder lists that file too.

## Success looks like

- Make a copy of a file in Garden club opens the copy already in Garden club.
- New document from that file does the same.
- She never picks a folder, and My Drive does not gain those files.
- The folder name is visible on the new file as soon as it opens.

## Better than Google Drive

- There is no folder dialog between her and the copy.
- She can see where the new file went without going back to the folder first.
- The file stays with the one it came from, instead of appearing at the top of My Drive.

## Gaps and notes

- Recorded. Rosa signs in, opens Garden club, and opens Watering rota. The control next to the title says Garden club. File › Make a copy does not open a folder dialog. The copy opens with Garden club next to the title. Garden club lists the rota and the copy, and My Drive lists neither. She opens the copy and chooses File › New › Document. The new document shows Garden club, and the folder lists it too.
- A file already at My Drive still creates its copy and new files at My Drive. There is no folder dialog.
- If she cannot create in that folder, the new file is created at My Drive and the control says My Drive.
- Open and Save as still start browsing at the top of My Drive.
